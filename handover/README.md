# Handover package

Open `index.html` in a browser. No build step is required.

**Do not deploy this folder** to the public web root (`/var/www/bino-foundry` or CDN). It is local / private documentation only. Production deploy syncs `frontend/dist` only; unknown URLs such as `/handover` should show the SPA 404 page.

This folder covers handover items **3 (configuration)**, **4 (deployment)**, **5 (access)**, and **7 (development notes)** in English. Code (item 1) lives in GitHub; Supabase transfer (item 2) and the 30-day reference site (item 6) are operational steps outside this folder.
